# 티켓 예매 플랫폼

---

## 현재 진행 상황

- **OAuth 2.0 소셜 로그인 구현**: `oauth` 패키지를 이용한 소셜 로그인 기능을 개발하고 있습니다.
- ***

## 완료 상황

_회원 인증 시스템 (Authentication)_

- **이메일 기반 회원가입**: 이메일, 비밀번호, 이름, 생년월일을 입력받아 가입을 처리합니다. (`/auth/register`)
- **이메일 인증**: 회원가입 시 인증 코드를 이메일로 발송하고, 코드 검증을 통해 이메일 소유를 확인합니다. (`/auth/send-verification`, `/auth/verify-code`)
- **로그인**: 이메일과 비밀번호로 사용자를 인증하고, 성공 시 JWT 토큰을 발급합니다. (`/auth/login`)
- **비밀번호 암호화**: `BCryptPasswordEncoder`를 사용하여 비밀번호를 안전하게 해싱하여 저장합니다.

_보안 (Security)_

- **JWT 기반 Stateless 인증**: 서버에 세션을 저장하지 않는 토큰 기반 인증 방식을 채택하여 확장성을 높였습니다.
- **API 접근 제어**: Spring Security를 사용하여 인증이 필요한 API와 공개 API를 명확히 구분하고 접근을 제어합니다.
- **CORS 설정**: 프론트엔드와의 안전한 교차 출처 리소스 공유를 위해 CORS 설정을 완료했습니다.
